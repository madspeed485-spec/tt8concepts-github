# Security policy

T&T 8 Concepts (https://tnt8concepts.com) is a static Astro site hosted on GitHub Pages.

## Supported versions

Only the live site, built from the `main` branch, is supported. Other branches are not.

## Reporting a vulnerability

Email [tony@tnt8concepts.com](mailto:tony@tnt8concepts.com), or use GitHub's private vulnerability reporting on the Security tab.

Please do not open a public issue.

## What to include

- The URL where you saw the problem
- Steps to reproduce it
- The impact, and what an attacker could do

## What to expect

We aim to reply within 7 days. There is no bug bounty.
